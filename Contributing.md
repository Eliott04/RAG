# Contribution

Créer une branche dédiée avant toute modification.

## Workflow

1. Mettre à jour la branche `main`.
2. Créer une branche dédiée à la tâche.
3. Créer des commits clairs.
4. Ouvrir une Pull Request avant la fusion.


## Avant une Pull Request

Vérifier les changements avec `git diff` et décrire les tests effectués.
